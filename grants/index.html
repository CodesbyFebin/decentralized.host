Grant & Funding Templates

Draft applications for real, existing grant/funding programs — for you to personalize and submit yourself through each program's actual process.

⚠️

These are drafts, not live claims. Every [bracketed] field is a real placeholder — fill in your own name, links, and ask before sending anything. Nothing here claims an existing relationship, endorsement, or funding that hasn't happened.

Application processes, forms, and URLs change over time — verify the current process on each program's own site before submitting. Where a program relates to tech this project doesn't use yet (Filecoin, IPFS, Akash), the draft proposes building that integration with the grant, rather than claiming it already exists.
